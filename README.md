# AIE-skills

Agent skills for photo editing, including exposure/ color grading/ presets/ cutting and many more.

## Taste

The skill urges the agent to learn the user's taste, helping it adapt to the user's preferred aesthetics.

## Tools

The skill includes multiple tools (python scripts), including histograms, contrast, warmth, saturation, cropping, local retouching (radial/rect adjustments, blemish healing, skin softening), noise reduction, Tyndall-light (volumetric rays), etc.
